📚 Internal Educational Management System

The **Internal Educational Management System** is a custom-built solution for the **Sector Higher Educational Institute - Panadura**, designed to streamline and automate various administrative tasks. This system manages critical functions such as **student information**, **course enrollment**, **grading**, and **faculty management**, ensuring efficient operations within the institute.

🌟 Key Features

- 🔐 **Secure Login**: Role-based access for administrators, faculty, and students, ensuring data privacy and security.
- 👥 **User Roles**: Different user roles with specific permissions, allowing for controlled access to different features.
- 📋 **Student Information Management**: Tracks and stores student profiles, academic progress, and other essential details.
- 📝 **Course Enrollment**: Easy course registration and enrollment process for students, with faculty handling course assignments.
- 🏅 **Grades Management**: Faculty can enter and update student grades with real-time updates to the student's profile.
- 🎓 **Faculty Management**: Streamlines faculty information and their assigned courses.
- 🖥️ **User-Friendly Interface**: Simplified and intuitive design for seamless navigation across modules.

🛠️ Requirements

To run this project, you will need:

- **NetBeans IDE**: The development environment to run and manage the project.
- **MySQL**: For database management.
- **Java (with Ant)**: The core language used for development.

🚀 How to Run

1. **Clone the Repository**  
   `git clone https://github.com/your-username/internal-educational-management-system`

2. **Open in NetBeans**  
   Open the project folder in **NetBeans IDE**. The source code is structured and developed using Java + Ant.

3. **Add Required JAR Files**  
   You will need to manually upload the JAR files located in the `Sector_Institute` folder. Ensure the dependencies are correctly linked to avoid runtime errors.

4. **Run the Application**  
   Once the project is set up in NetBeans, simply click the `Run` button to start the application.

🛠️ Troubleshooting

Missing JAR Files: If you encounter any errors while running the project, it may be due to missing JAR dependencies. These JAR files can be found in the `Sector_Institute` folder. Make sure they are correctly added to your NetBeans library.
